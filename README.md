# Axiom Trading Journal

A clean, modern forex trading journal web application and landing page designed for disciplined traders.

## Features
- **Landing Page**: 3D interactive WebGL simulation, feature showcase, and responsive navigation.
- **Trading Journal App (`/app/`)**: Full-featured journal tracking trade executions, risk-to-reward ratios, psychology ratings, equity curves, calendar heatmaps, and cloud sync.
- **Educational Knowledge Base**: In-depth blog guides on risk management, prop firm evaluations, and trading psychology.
- **Theme Support**: Seamless Dark and Light mode toggles across auth screens and dashboards.

## Getting Started

### Prerequisites
- Node.js (v18+)

### Development
```bash
npm install
npm run dev
```

### Build & Production
```bash
npm run build
```
